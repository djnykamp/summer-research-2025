These scripts are the result of summer research with Tay Netoff.
I researched 2 separate projects that I am naming 'rail gun' and 'onset response.'

The rail gun project uses Bayesian optimization to search for configurations that produce an action potential in one direction.

The onset response project searches for the optimal waveform that sets up a high-frequency block but does not cause an action potential in the process. I approached this project in two ways, so there are 2 folders associated with this project.
